# Phase 17 — Character Agency & Work Willingness
# Master Plan — EXACT

## 0. Authority and baseline

Governed by the canonical Roadmap and the Phase 17–24 Planning Authority. Start only from accepted
Phase 16 integration. Required recon: Persona/C1, emotion, relationship/C5, C4 plans, motivation,
DialogueBrain/Single Mouth, WorkContract and the Phase 16 permission/execution boundary.

## 1. Goal

Give Furina a bounded, explainable subjective policy for willingness, refusal, negotiation,
initiative and style of participation while preserving user authority and technical truth.

Phase 17 answers:

```text
Do I want to engage?
How do I express that?
Should I approach, wait, negotiate, refuse or follow up?
```

It never answers whether an unauthorized operation may execute.

## 2. Frozen separation

```text
Phase 16: capability / health / permission / budget / verification
Phase 17: subjective willingness / timing / style / character preference
```

- A willing decision cannot widen WorkContract or approval scope.
- A refusal cannot fabricate technical failure.
- A backend preference cannot override explicit user choice, capability or health.
- Persona/relationship/emotion may influence policy but never mutate themselves from the decision.
- All user-visible expression routes through the existing Single Mouth.

## 3. Durable and non-durable state

Prefer deterministic policy over a new durable store. Reuse C4/C5/C6 truth and existing runtime
state. Any new agency operational state must be bounded, typed, provenance-linked and explicitly
non-authoritative. A new cognition Store is forbidden.

## 4. Required behavior

- explainable willingness result: engage / negotiate / defer / refuse / silent;
- reason categories separated from private chain-of-thought;
- explicit user command priority and emergency-stop supremacy;
- P17-D1 plan/goal proactive follow-up with presence, timing, quota, mute and cooldown;
- P17-D2 relationship climate to approach/silence policy without visible intimacy meter;
- late/stale plans cannot trigger initiative;
- refusal/initiative frequency bounded across restart;
- pressure-regression suite protects Furina identity under work stress.

## 5. Delta order

```text
17A Agency Decision Contract
→ 17B Willingness / Refusal / Negotiation
→ 17C Proactive Follow-up & Relationship Climate Policy
→ 17D Work-Persona Integration & Final Gate
```

## 6. Phase gate

Phase 17 closes only when production-path tests prove that subjective policy changes expression
and initiative without widening permissions, fabricating task truth, bypassing Single Mouth or
creating unbounded interruption behavior. Controlled human dialogue/UAT is mandatory.
