# Phase 21 — Delta Task Briefs — EXACT

## 21A — Asset Standard & Character Identity Lock

Freeze canvas topology, scale, directions, pivots, foot/hit anchors, safe margins, frame timing,
alpha/color rules, naming, manifest schema, provenance and licensing fields. Produce an approved
identity board and reference poses. Resolve conflicts with the Phase 20 body contract before bulk
asset work.

## 21B — Core Life Animation Pack

Produce and review neutral, idle variants, walk/turn, sit, sleep/wake, eat, play, pet and poke
families for required directions. Define entry/loop/exit frames, interruption points and fallback
clips. Validate silhouette, anchors and temporal continuity frame by frame.

## 21C — Work, Emotion, Prop & Transition Pack

Produce thinking, executing, approval-wait, verifying, repair, result, cancellation and failure
families plus approved emotions, props and state transitions. Visual work states must map to Phase
20 keys and must not invent task success, urgency or emotional state.

## 21D — Packaging, Resolver & Automated QC

Build deterministic manifests and packages with version/hash/provenance data. Check dimensions,
frame counts, alpha edges, anchors, missing references, duplicate keys, bounds and fallback
reachability. Demonstrate clean install, upgrade and rollback of an asset pack.

## 21E — Visual Acceptance & Long-run Final Gate

Run all clips and transitions in the real Phase 20 desktop body across scale, DPI and monitor cases.
Perform a named human visual review, asset-rights audit, long-run animation soak and three full test
suite runs. The evidence branch contains no feature fixes; defects return as bounded micro-patches.
